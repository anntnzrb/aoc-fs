# 2017 journal

Per-day learning log: the key idea, what surprised us, measurements, and
lessons that later days should apply. No puzzle text, no answers.

## Day 01

- Key idea: both parts compare each element of a circular sequence with the
  element a fixed step ahead; one `matchSum step` helper over an array with a
  modulo index covers both (step 1, then step n/2).
- Surprise: none in the algorithm. Fantomas reflowed a multi-line `Seq.fold`
  onto one line, so the first gate failed on format drift.
- Measurements: not taken; `bench` is planned.
- Lessons:
  - Run `nix develop -c just fmt` before `just check`; the gate rejects any
    layout Fantomas would change.
  - Part-2 fixtures need both answers: work out each example's part-1 answer
    by hand from the statement, never from solution output.
  - The fixture runner adds one test per fixture; check that the test count
    rises by the number of fixtures you wrote, which proves they ran.
  - Write the `Input` parser as an all-or-nothing `Result` fold that rejects
    empty input and bad characters; solvers derive their own arrays from it.
